Here is exactly what is happening and how to fix it:

The Errors (Bad Value)
The [ and ] brackets in your src attributes (like
src="[path-to-your-image-1.jpg]") are not valid characters for a
web browser. Browsers expect a real file path. Because these
were just placeholders, the validator rejected them.

Fix: Change the src to a real image file name, or if you don't
have images yet, use a valid placeholder URL.

The Warnings (Article lacks heading)
An <article> tag is meant to contain a self-contained piece of
content, and the rules of HTML say it should have a heading
(like <h2> or <h3>) so screen readers and search engines know
what the article is about. My gallery articles just had an image
and a paragraph, so the validator warned you.

Fix: In the gallery, change the <p><strong>[Artwork 1 title]</strong></p>
into an <h3>[Artwork 1 title]</h3>.
